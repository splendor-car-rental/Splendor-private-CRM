# معيار الطباعة الرسمي — Splendor OS 3.0

هذا المستند يحدد معيارًا واحدًا لكل مستندات النظام القابلة للطباعة.

## 1. الهيدليتر
- المصدر الوحيد المعتمد: نموذج الهيدليتر الرسمي المقدم من مالك النظام.
- يمنع إعادة رسمه أو إعادة تركيب شعاره أو نصوصه أو أرقامه داخل HTML/CSS/PDF.
- يمنع استخدام placeholder أو أصل بديل عند توفر الأصل الرسمي.
- يجب أن يحتفظ رأس الصفحة والفوتر بنسبهما وموضعهما الأصليين عند الطباعة.

## 2. جسم المستند
- مقاس الصفحة: A4.
- اتجاه العربية: RTL حيث يلزم، مع إبقاء الأرقام والبيانات اللاتينية في اتجاهها الصحيح.
- المحتوى يبدأ داخل المنطقة البيضاء المخصصة في النموذج ولا يغطي الرأس أو الفوتر.
- المستندات متعددة الصفحات يجب أن تمنع القص أو التداخل مع مناطق الهوية.

## 3. الختم
- استخدام الختم الأحمر الرسمي الموجود في `src/server/assets/splendorStampAsset.ts`.
- يوضع عند نقطة اعتماد/توقيع الشركة التي يتطلبها النموذج.
- لا يُكرر الختم على كل صفحة تلقائيًا إلا إذا كان النموذج المعتمد يقتضي ذلك.

## 4. قائمة المستندات المطلوب تدقيقها
- عقود الإيجار.
- عروض الأسعار.
- الفواتير.
- الإيصالات.
- كشوف الحساب.
- نماذج تسليم واستلام المركبات.
- نماذج الفحص.
- مستندات الشركات والعملاء.
- مستندات الإيجار المنتهي بالتملك.
- أي مستند PDF آخر ينشئه النظام.

## 5. معيار القبول
لا يعتبر المستند معتمدًا للطباعة إلا بعد التحقق من:
- مطابقة الهيدليتر للمصدر الرسمي.
- موضع المحتوى والهوامش.
- A4 وعدم القص.
- RTL واللغة الثنائية عند الحاجة.
- موضع الختم وعدم تداخله مع النص.
- سلامة الصفحات المتعددة.
- نجاح إنشاء PDF فعلي قابل للطباعة.

## 6. الوضع الحالي
الأصل الرسمي تم تقديمه في جلسة العمل الحالية، بينما أصل LTO البرمجي الموجود في المستودع ما زال placeholder بحجم 1×1. لذلك يبقى استبداله بالأصل الرسمي خطوة تنفيذية لازمة قبل إعلان مطابقة مستندات LTO.
